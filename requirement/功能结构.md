## 运营管理后台

### 圈子配置（5.1）

- 创建圈子
  - 圈子类型
    - 必填。单选：在线工程师/产品社区/车型圈子/其他

  - 圈子名称
    - 必填。≤200字符。支持多语言。

  - 圈子描述
    - 必填。≤1000字符。支持多语言

  - 封面图
    - 必填。webp/png/jpg格式，3M以内

  - 访问权限
    - 必填。多选：全部用户/车主/授权车主/官方号

  - 发表权限
    - 必填。多选：全部用户/车主/授权车主/官方号

  - 回复权限
    - 必填。多选：全部用户/车主/授权车主/官方号/作者

  - 追问权限
    - 必填。多选：全部用户/车主/授权车主/官方号/作者

  - 功能启用
    - 必填。多选：回复 / 图片 / 视频 / 选择车辆 / 车辆累计公里数

- 圈子列表
  - 列表字段
    - 排序序号
    - 圈子名称
    - 圈子类型
    - 封面图
      - 支持点击预览

    - 背景颜色
    - 圈子描述
    - 内容数
    - 回复数
    - 启用状态
      - 创建时默认启用， 禁用后圈子不可访问

    - 创建时间
      - 时间控件选择开始时间、结束时间

  - 圈子操作
    - 查看
      - 仅查看不可编辑

    - 编辑
      - 圈子类型创建后不可修改。其他字段同创建圈子，均可修改

    - 删除
      - 二次确认后软删除：isdeleted标记为“true”
        - 提示文案：删除圈子将同步删除圈子内容，确定要删除吗？

      - 删除圈子同步删除圈子的内容，软删除
      - 删除后圈子及其内容不可访问，显示该圈子/内容不存在

  - 筛选项
    - 圈子名称
      - 模糊搜索圈子名称

    - 圈子类型
      - 单选：在线工程师/产品社区/车型圈子/其他

    - 启用状态
      - 单选：启用/禁用

    - 创建时间
      - 时间控件选择开始时间、结束时间

- 批量管理
  - 排序
    - 排序数字为正数。按排序数据由小到大排序。排序规则：排序数字>发表时间例序

### 问题发布（5.3）

- 表单字段
  - 标题
    - 必填，5-400 字符

  - 描述
    - 选填，≤10000字符

  - 图片/视频
    - 选填，图片+视频≤9 张，图片 ≤5MB，视频≤50MB，60秒以内
    - 图片和视频在客户端压缩后上传，格式统一转为jpg、mp4
    - 上传中显示“取消”按钮，点击按钮取消上传/上传成功后显示“移除”按钮，点击按钮移除该图片/视频
    - 上传成功后点击图片/视频进行预览

  - 选择车辆
    - 如果当前圈子启用了该发布设置项，且当前用户是车主或授权车主，则显示该设置项。
      - 必填，默认选中当前车主的默认车辆，点击弹出选择辆界面。

    - 如果当前圈子未启用该设置项，或当前用户不是车主/授权车主，则不显示该设置项。

  - 总里程
    - 如果当前圈子启用了该发布设置项，且当前用户是车主或授权车主，则显示该设置项。
      - 必填。占击弹出填写车辆里程界面。

    - 如果当前圈子未启用该设置项，或当前用户不是车主/授权车主，则不显示该设置项。

- 发表按钮
  - 默认状态
    - 发表按钮默认置灰，当用户完成必填项且不存在上传中的图片/视频时显示为可提交状态

  - 提交中
    - 提交问题到App后端，App后端请求UOP接口进行敏感词校验
      - 校验通过：后端保存问题并推送问题到UOP
      - 校验不通过：接口返回失败，App弹窗提示用户

    - 按钮显示“加载中”动画

  - 提交成功
    - APP弹窗提示用户发表成功以及运营人员工作时间等信息文案

### 内容搜索（5.5）

- 搜索引擎

- 搜索范围
  - 问题标题 + 内容
  - 仅搜索审核状态为审核通过且公开状态为公开的内容

- 分词器
  - IK Analyzer
    - 负责中文语义理解。索引时用 ik_max_word 保证召回，搜索时用 ik_smart 保证精准

  - ICU Analyzer
    - 基于 Unicode 标准。通过 icu_tokenizer 识别非空格语系（如泰语、老挝语）的边界，并配合 icu_folding 滤镜层实现重音忽略、全半角归一化。

- 排序规则
  - should
    - 标题命中的分值贡献加成
      - title^3, content^1

    - 意图紧密度补偿 (词序一致性)
      - slop: 2

  - functions
    - 回答数加成
      - (权重 0.1)

    - 时效性高斯衰减
      - 365天衰减至0.5

  - score_mode: sum
  - boost_mode: multiply

- 搜索结果
  - 命中关键词高亮
  - 无限滚动加载
