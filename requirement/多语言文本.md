## 工程化建议

1. **CI 校验**：用脚本对比 PRD 中所有 i18n key 与 `locales/*.json` 是否一致；缺 key 报错。
2. **泰文翻译**：标 🟡 的条目需在交付前由本地化团队复核；建议接入 LSP（Language Service Provider）流程。
3. **回退策略**：未翻译的 key 回退到 `en-US`，仍缺则展示 key 本身（便于发现）。
4. **生成方式**：建议提供脚本 `scripts/extract-i18n.ts`，自动从本文件抽取生成各 locale JSON。
5. **新增规则**：新增 PRD 章节涉及 UI 文本时，必须同步更新本文件，并在 PR 中标记 `i18n-impact`。
