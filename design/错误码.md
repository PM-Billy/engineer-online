# Engineer Online — 错误码注册表

> **用途**：本文档是错误码的**单一真相源（SSOT）**。所有后端异常响应必须使用本表定义的错误码。
>
> **关联文档**：
> - 错误码体系设计：`standard/技术架构.md` §5.3
> - 各模块异常场景：`requirement/modules/05.x-xxx.md` §5.x.5

---

## 1. Overview（概述）

定义 Engineer Online 功能的错误码注册表，所有后端异常响应的单一真相源。

**成功响应**：统一返回 `code: 0`，无需注册。示例：
```json
{ "code": 0, "message": "success", "data": { ... }, "timestamp": 1715500800000 }
```

### 1.1 错误码格式

采用 **分层 + 模块** 编码策略，4 位数字，按段分配：

| 段 | 范围 | 类别 | 说明 |
|---|---|---|---|
| 0 | 0 | 成功 | success |
| 1xxx | 1000-1999 | 通用/参数 | 参数校验、限流、签名等 |
| 2xxx | 2000-2999 | 认证/权限/用户 | 登录、Token、角色、用户 |
| 3xxx | 3000-3999 | 圈子模块 | Group 相关 |
| 4xxx | 4000-4999 | 问题模块 | Question 相关 |
| 5xxx | 5000-5999 | 回答模块 | Answer 相关 |
| 6xxx | 6000-6999 | 审核/内容 | 审核、敏感词、UOP |
| 7xxx | 7000-7999 | 消息/推送 | Notification、FCM |
| 8xxx | 8000-8999 | 文件/翻译 | File、Translate、OSS |
| 9xxx | 9000-9999 | 系统/外部 | 数据库、缓存、第三方服务 |

## 11. 使用约定

### 11.1 后端

```java
// 抛出业务异常
throw new BusinessException(ErrorCode.CONTENT_SENSITIVE);

// 全局异常处理器统一包装响应
@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(BusinessException.class)
    public Result<?> handle(BusinessException e) {
        return Result.fail(e.getCode(), e.getMessage());
    }
}
```

### 11.2 前端

```typescript
// 统一错误处理
switch (response.code) {
  case 2001: router.push('/login'); break;
  case 2004: showToast(t('error.forbidden')); break;
  case 6001: showToast(t('error.sensitive_content')); break;
  default: showToast(t('error.system'));
}
```

### 11.3 响应格式

```json
{
  "code": 6001,
  "message": "Content contains sensitive words",
  "data": null,
  "timestamp": 1715500800000
}
```

## 12. 变更流程

新增错误码必须：
1. 在本表对应段追加一行
2. 同步对应模块 PRD 的 §5.x.5 异常处理
3. 更新 `CHANGELOG.md`
4. 后端 ErrorCode 枚举类同步新增

**禁止**：直接在代码中使用魔法数字，必须通过 ErrorCode 常量引用。
