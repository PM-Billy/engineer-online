# Prompt: 管理后台页面生成

> **适用角色**：后台前端
> **输出工件**：Vue 3 + Ant Design Vue + Pinia 管理后台页面
> **适用模块**：5.1 圈子管理 / 5.7 问题管理 / 5.8 回答管理 / 5.9 用户管理

---

## 你需要先读这些文档

1. `tasks/任务清单.md` 中对应任务行（如 `GROUP-05`、`QM-04`、`AM-04`；若按模块直接开发可跳过）
2. `requirement/00-需求总览.md` 第 1.5 节（角色权限）、第 6 节（全局规则）
3. `design/权限设计.md`（Permission Code）
4. `requirement/modules/<目标模块>.md` 全文（如 `requirement/modules/05.07-问题管理（管理后台）.md`）
5. `standard/技术架构.md` 第 3.3 节（后台前端规范）、第 5 章（接口）、10.2（脱敏）
6. `standard/UI设计规范.md` 第 4.6 节（管理后台页面）、附录 C（Ant Design Vue 主题）
7. `requirement/多语言文本.md` 第 7 节（后台管理）

## 你需要输出

### 1. 页面文件 `views/<module>/<Page>.vue`

要求：
- 列表页：`a-table` + 筛选区 `a-form` + 分页 `a-pagination` + 批量操作栏
- 编辑页：右侧 `a-drawer` 600px，标签右对齐宽度 120px
- 鉴权：`v-permission="['question:audit:any']"`，无权限时元素不渲染
- 筛选条件全部封装在 `<SearchForm>` 通用组件中

### 2. API 模块 `api/<module>.ts`

要求：
- 与 PRD 5.x.10 API 契约 一一对应
- 使用 Axios 封装实例（`utils/request.ts`）
- 类型 import 自 `types/admin.d.ts`

### 3. Store `stores/<module>.ts`

要求：
- 列表分页状态、筛选条件、选中行 ID 等

## 严格约束

| 项 | 规则 |
|---|------|
| **追溯注释** | 每个生成文件顶部用注释标注引用的 BR/AC 编号（如 `// BR-5.7-03, AC-5.7-04`），便于反向追溯 |
| **Permission Code** | 使用 `design/权限设计.md` 中的常量，禁止裸字符串 |
| **批量操作** | 单次 ≤ 100 条；超出前端拦截，提示 i18n 文本 |
| **二次确认** | 删除/驳回必须 `Modal.confirm`；驳回需输入原因（必填） |
| **脱敏展示** | 手机号 `138****1234`、邮箱 `a***@gmail.com`，遵循 SEC-05 |
| **操作日志** | 所有写操作触发后端记录，前端无需显式触发 |
| **抽屉大小** | 列表页右侧抽屉宽度 600px |
| **筛选区折叠** | 字段 > 6 个时折叠，"展开筛选"按钮 |
| **导出/打印** | 不在本期范围内，遇到需求列入 OQ |

## 反例

```vue
<td>{{ row.poster_phone }}</td>

<!-- ✅ -->
<td>{{ maskPhone(row.poster_phone) }}</td>
<a-popconfirm :title="t('common.confirm.delete')" @confirm="del(row.id)">
  <a-button danger>{{ t('common.btn_delete') }}</a-button>
</a-popconfirm>
```
