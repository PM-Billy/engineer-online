# Prompt: 测试用例生成

> **适用角色**：测试 / QA
> **输出工件**：JUnit 单元测试 / Playwright E2E / Postman/Newman API 集合

---

## 你需要先读这些文档

1. `tasks/任务清单.md` 中对应任务行（如 `TEST-02`、`TEST-03`；若按模块直接开发可跳过）
2. `requirement/modules/<目标模块>.md` 全文（重点 5.x.4 BR、5.x.5 EX、5.x.9 AC）
3. `requirement/00-需求总览.md` 第 6-7 节（全局规则 / NFR）
4. `standard/技术架构.md` 第 5 章（错误码）、第 11 章（性能目标）
5. `requirement/多语言文本.md` 校验 UI 文本的语言切换

## 你需要输出

### 1. 单元测试 `<Module>ServiceTest.java`

要求：
- 一个 BR / EX 至少对应一个测试方法
- 方法命名：`should_<expected>_when_<condition>`，例如 `should_throw_QUESTION_TITLE_TOO_SHORT_when_title_length_less_than_5`
- 使用 `@Mock` 隔离外部依赖（Mapper / 第三方服务）
- 覆盖率目标：核心 Service 方法 ≥ 80%，关键路径 ≥ 95%
- 每个测试在末尾注释来源：`// AC-5.3-05`

### 2. E2E 测试 `e2e/<feature>.spec.ts`（Playwright）

要求：
- 覆盖 5.x.9 中所有 AC 编号
- 每个 `test()` 名称对应 AC：`test('AC-5.2-01: 首页加载显示 Hot Tab 列表', ...)`
- 数据准备使用 `beforeEach` 创建固定 fixture，避免依赖测试顺序
- 网络请求拦截 mock：`page.route(...)` 模拟错误码场景

### 3. API 集合 `postman/<Module>.postman_collection.json`

要求：
- 每个接口：成功 + 主要错误（401 / 403 / 4xxx 业务码）的样例请求
- 使用 `design/错误码.md`做断言
- 环境变量：`{{baseUrl}}`、`{{adminToken}}`、`{{userToken}}`

### 4. 性能测试 `k6/<feature>.js`

要求（仅核心路径）：
- 100 并发持续 1 分钟
- P95 响应时间断言遵循 `standard/技术架构.md` 11.1
- 输出 JSON 报告供 CI 解析

## 严格约束

| 项 | 规则 |
|---|------|
| **追溯注释** | 每个生成测试用例顶部用注释标注引用的 BR/AC 编号 |
| **追溯** | 每个测试方法必须标注关联的 BR/EX/AC 编号 |
| **三类覆盖** | 正常 + 异常 + 边界 三类必须各覆盖 |
| **mock vs real** | 单元测试 mock；集成测试用 H2 内存库；E2E 用 dev/test 环境 |
| **Flaky** | 时间敏感的测试（相对时间）用固定时间戳 |
| **多语言** | i18n 测试至少校验 zh/en，泰文上线前抽样 |
| **数据清理** | E2E 在 afterEach 清理脏数据，避免污染 |

## 自检清单（输出末尾必填）

- [ ] 覆盖的 AC 编号清单（应等于 5.x.9 全部）
- [ ] 覆盖的 BR 编号清单
- [ ] 覆盖的 EX 编号清单

## 反例

```java
// ❌ 测试名无信息量
@Test
void test1() { ... }

// ❌ 没有断言异常类型
assertThrows(Exception.class, () -> svc.create(dto));

// ✅
@Test
@DisplayName("AC-5.3-05: 标题仅 2 字符时抛 QUESTION_TITLE_TOO_SHORT")
void should_throw_QUESTION_TITLE_TOO_SHORT_when_title_length_less_than_5() {
    var dto = QuestionCreateDTO.builder().title("ab").build();
    var ex = assertThrows(BusinessException.class, () -> service.create(1L, dto));
    assertEquals(ErrorCode.QUESTION_TITLE_TOO_SHORT, ex.getCode());
}
```
