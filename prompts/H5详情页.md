## 你需要输出

### 1. 页面文件 `apps/h5-detail/pages/question/[id].vue`

要求：
- `<script setup lang="ts">` + Composition API
- 严格使用 Design Token CSS 变量（不允许写死颜色 / 字号 / 间距）
- 状态：`loading / error / empty`
- 详情页结构：问题区 + 操作区（翻译/删除）+ 回答列表 + 嵌套回复 + 输入区
- 所有 UI 文本通过 `t('xxx.yyy')`，禁止硬编码

### 2. Pinia Store `stores/question.ts`

要求：
- 管理详情数据、回答列表、投票状态
- 暴露 `actions` 调用 API
- 错误处理统一走 `utils/request.ts` 拦截器

### 3. Composable

- `composables/useTranslate.ts`
- `composables/useVote.ts`
- `composables/useBackHandler.ts`（监听原生返回事件）

### 4. 业务组件 `components/`

- `QuestionHeader.vue` — 问题区
- `AnswerCard.vue` — 回答卡片（含投票/采纳/翻译/回复）
- `ReplyComposer.vue` — 回复输入框
- `TranslateButton.vue` — 翻译切换

### 5. TypeScript 类型 `types/api.d.ts`

要求：
- 与 PRD 5.4.6 数据对象 / 5.4.10 API 契约 一一对应

## 严格约束

| 项 | 规则 |
|---|------|
| **追溯注释** | 每个生成文件顶部用注释标注引用的 BR/AC 编号（如 `// BR-5.4-03, AC-5.4-03`），便于反向追溯 |
| **i18n** | 任何 UI 文本必须从 `t()` 取，不允许 `<span>Reply</span>` |
| **Design Token** | 颜色 `var(--color-text-primary)`、字号 `var(--font-size-h3)`、间距 `var(--space-4)` |
| **JSBridge** | 调用原生能力前必须检查 `window.flutterBridge` 是否存在；mock 模式可降级 |
| **错误码** | 使用 `design/错误码.md`（如 401 → 跳登录、4002 → 标题校验提示） |
| **图片懒加载** | `<van-image lazy-load>` |
| **图片预览** | 通过 JSBridge 调原生 `openImagePreview`，不在 H5 内实现 |
| **返回手势** | 通过 `useBackHandler` 拦截原生返回事件 |
| **安全区** | 顶部 / 底部 padding 使用 `env(safe-area-inset-top/bottom)` |
